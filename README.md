# Jayvik Labs — Cyber Security Internship 2026

This repository is where I'm documenting my third cybersecurity internship. I'll be using it to keep track of my daily assignments, practical exercises, research, and the things I learn along the way.

Rather than just completing a task and moving on, I want to understand what I'm doing, keep evidence of my work, and have something useful to look back on when I need to revisit a concept.

## About the Internship

I'm joining Jayvik Labs as a Cyber Security Intern for a three-month internship. The focus is on developing practical cybersecurity skills through assigned tasks, research, and hands-on exercises.

The learning areas include Linux and Kali Linux, networking, reconnaissance, vulnerability assessment, web and API security, penetration testing, traffic analysis, incident response, OSINT, and other cybersecurity topics covered during the internship.

I'll document the work as I progress, including the methods I use, the tools I practise with, the results I observe, and the lessons I take away from each task.

## What You'll Find Here

I'll organize the repository into three monthly sections, with separate folders for each week and day.

- **Daily tasks:** What I was assigned and how I approached it.
- **Practical work:** Exercises, commands, tool usage, and observations where relevant.
- **Screenshots and evidence:** Supporting material from completed tasks, with sensitive information removed.
- **Learning notes:** Concepts I understood, mistakes I encountered, and things I need to practise further.
