# Day 08 — Networking Challenge

## Overview

This challenge brought together several networking concepts through practical investigation, knowledge quizzes, and a network address calculation challenge.

## Tasks Completed

### Task 1 — Network Identity

Reviewed network configuration fields, including IPv4 addressing, subnet mask, default gateway, DNS server, MAC address, and DHCP status.

### Task 2 — OSI Matching Quiz

Completed the OSI model matching quiz.

### Task 3 — IP Classification Quiz

Completed the IP address classification quiz.

### Task 4 — DNS Investigation

Used `nslookup` to investigate DNS resolution and understand how domain names are mapped to IP addresses.

### Task 5 — Network Path Investigation

Used `tracepath` in Kali Linux to observe network hops and learn how path investigation helps troubleshoot connectivity.

### Task 6 — Network Address Calculation

Completed the CTF challenge by calculating the network address, broadcast address, and usable host range for an IPv4 subnet.

## Key Takeaways

This assignment strengthened my understanding of DNS, IPv4 addressing, network paths, and subnet calculations. It also reinforced the importance of combining theoretical knowledge with practical troubleshooting.
