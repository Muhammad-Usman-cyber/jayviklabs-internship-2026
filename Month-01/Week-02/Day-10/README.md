# Day 10 — Linux Files and Permissions

## Overview

Today's assignment focused on Linux file management and permissions. I practised creating files and directories, viewing file contents, copying and renaming files, and modifying permissions through the terminal.

## Topics Covered

- Creating directories with `mkdir`
- Creating files with `touch`
- Viewing file contents with `cat`
- Copying files with `cp`
- Moving and renaming files with `mv`
- Understanding file listings with `ls -l`
- Changing permissions with `chmod`
- Understanding `755` and `644` permission modes
- Learning about Linux ownership and the `/etc`, `/home`, and `/var` directories
- Understanding the security risks of incorrect permissions

## Practical Work

I practised the required commands inside my `day10_lab` directory, including file creation, copying, renaming, and permission changes.

## Key Takeaway

Linux file permissions are an important part of system security. Understanding how ownership and read, write, and execute permissions work helps prevent unauthorized access and accidental changes.
