# Day 09 — Linux Basics

## Overview

Today's assignment focused on Linux fundamentals, filesystem navigation, and understanding common terminal commands used to interact with a Linux system.

## Topics Covered

- Linux and Linux distributions
- Kali Linux and its role in cybersecurity
- Terminal basics
- Current user and hostname identification
- Working directory navigation
- Listing files and directories
- Detailed and hidden-file listings
- Absolute and relative paths
- Root directory versus root user
- The importance of Linux skills in cybersecurity

## Practical Work

Practiced the following commands on my own Linux system:

| Command | Purpose |
|---|---|
| `whoami` | Displays the current username |
| `hostname` | Displays the system hostname |
| `pwd` | Prints the current working directory |
| `ls` | Lists directory contents |
| `ls -l` | Displays a detailed listing |
| `ls -a` | Includes hidden entries |
| `cd /` | Navigates to the root directory |
| `cd ~` | Navigates to the home directory |

## Key Takeaways

Understanding basic Linux commands makes it easier to navigate a system, locate files, inspect system information, and build a foundation for cybersecurity labs and investigations.
