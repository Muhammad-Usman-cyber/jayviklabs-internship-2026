# Day 06 — IPv4 Addressing

## Overview

Today's task focused on understanding IPv4 addressing and identifying the main network configuration details on a computer.

## Topics Covered

- What IPv4 is and how its 32-bit address structure works
- Octets and subnet masks
- Network and host portions of an IP address
- Private and public IPv4 addresses
- Private IPv4 address ranges
- Loopback and APIPA addresses
- Default gateways
- Static and dynamic IP addressing
- DHCP
- Network and broadcast addresses
- The importance of IPv4 in cybersecurity

## Practical Work

I reviewed my computer's network configuration and practiced checking basic IP connectivity.

Commands used:

```text
ipconfig
ipconfig /all
ping 127.0.0.1
```

The exercises helped me understand how to identify network configuration fields and test the local TCP/IP stack.

## Key Takeaways

IPv4 addressing is an important networking foundation for cybersecurity. Understanding IP addresses, subnet masks, gateways, and DHCP helps with network troubleshooting, traffic analysis, and recognizing unusual network configurations.
