# Day 07 — IP Configuration

## Overview

Today's assignment focused on IPv4 configuration, subnet addressing, and checking network connectivity.

## Topics Covered

- Network, broadcast, and usable host addresses
- IPv4 `/24` prefix and subnet mask
- Default gateways and router interfaces
- Static IP configuration
- Cisco interface verification commands
- Interface status and administrative state
- The importance of verifying network settings
- IPv4 configuration in cybersecurity

## IPv4 Addressing Exercise

For the `192.168.100.0/24` network, I identified the network address, first usable address, last usable address, and broadcast address.

## Practical Work

I practiced inspecting network configuration and testing connectivity using:

```text
ipconfig /all
ping 127.0.0.1
ping 192.168.1.1
```

I also reviewed the purpose of Cisco IOS commands used to check interface status and enable an interface.

## Key Takeaways

Accurate IP configuration is essential for reliable connectivity and effective troubleshooting. Understanding subnet boundaries, gateways, and interface status also helps with network monitoring and cybersecurity investigations.
